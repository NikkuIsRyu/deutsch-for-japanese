# ドイツ語練習 / Deutsch für Japanischsprachige — build spec v1

Source plan: `Knowledge_Vault_App/docs/plan/MG_GERMAN_WEB.md` (owner decisions 2026-11-13). This file is the **contract** all contributors build against. If something here is impossible, stop and report instead of silently deviating.

## 0. Product

- Static web app (PWA) for **Japanese speakers learning German at A2 / B1 / B2**. Friends use **iPhones** (Safari, Home-Screen install).
- UI and explanations **in Japanese**; target language German. Landing page: Japanese plus **one short German line**.
- Target URL `https://deutsch.nikku.tech` (DNS pending). Until then served from GitHub Pages at `https://nikkuisryu.github.io/deutsch-for-japanese/`. **Every internal URL must go through the base path** (`import.meta.env.BASE_URL`), so that switching to the custom domain is an env change only.
- No accounts, no backend, no AI at runtime. Progress lives on the device, with export/import.
- Analytics: Umami, only when `PUBLIC_UMAMI_WEBSITE_ID` is set at build time (empty -> no script at all). Track only `umami.track(eventName, {mode, level})` with events `mode_start`, `session_done`. **Never send sentence text or typed answers.**
- `<meta name="robots" content="noindex">` on every page (unlisted, not private).

## 1. Tech rules

- Astro 7 (already installed), **no UI framework**: Astro components + small `<script>` blocks in TypeScript. No new runtime dependencies. No external fonts or CDNs at runtime (offline-capable). Only the optional Umami script is external.
- Pure logic lives in `src/lib/*.ts`, framework-free and DOM-free, importing siblings **with explicit `.ts` extensions** so `node --test` (Node 26, native type stripping) can run it. Tests in `tests/*.test.ts` / `*.test.mjs` using `node:test` + `node:assert/strict`.
- `npm run build` = `npm run content && astro build`. `npm test` runs all tests. Both must pass.
- Contributors **must not run git commands** other than `git status`/`git diff`. The integrator commits.
- Never edit `content/source/*` (copies of the review originals).

## 2. Data contracts

### 2.1 `src/data/sentences.json` (generated by `scripts/build-content.mjs`, never hand-edited)

```jsonc
{
  "version": 1,
  "generatedAt": "ISO timestamp",
  "count": 334,
  "items": [
    {
      "id": "JA-S-0326",                      // review_no from the CSV, stable card id
      "de": "Du solltest dem Lehrer lieber nicht widersprechen.",
      "ja": "先生に言い返さないほうがいいですよ。",
      "jaReading": "せんせいにいいかえさないほうがいいですよ。",
      "jaVariants": [ { "ja": "...", "jaReading": "..." } ],   // from ja_variants.csv, joined on item_id
      "cefr": "A2",                            // "A2" | "B1" | "B2" = highest level among tags, A2 if none
      "tags": ["modalverben"],                 // ids from §2.3 only
      "tokens": ["Du", "solltest", "dem", "Lehrer", "lieber", "nicht", "widersprechen."], // word-bank chips; punctuation stays attached to the preceding word
      "review": { "ja": "ok-unmarked" | "fixed", "de": "pending", "tags": "auto" }
    }
  ]
}
```

Rules: apply `content/review/fixes.json` (replace `ja` and `jaReading`, set `review.ja = "fixed"`). Fail the build on: duplicate ids, empty `de`/`ja`, unknown tag ids, a fix id not present. Also write `src/data/content-manifest.json` = `{ "sentences.json": "<sha256>" , "grammar.json": "<sha256>" }` and a test verifying it.

## 3. Pages (all under base path, `lang="ja"`, every German string wrapped in `<span lang="de">`)

| Route | 名前 | Content |
| :-- | :-- | :-- |
| `/` | ホーム | Title 「ドイツ語練習」 + German line *„Deutsch üben – für Freundinnen und Freunde aus Japan."*; level filter (A2/B1/B2, multi-select, stored); cards to each mode; today's due/new counts; iOS hint 「共有 → ホーム画面に追加」 shown only on iOS Safari when not standalone; "draft" note. |
| `/review/` | 復習 | SRS session: show JA (+ furigana toggle via jaReading line), user thinks/answers, reveal DE (+ audio), grade 4 buttons. Due cards first, then up to N new cards/day (setting, default 10). |
| `/build/` | 並べ替え | JA prompt; shuffled German token chips; tap to move into answer line, tap again to remove; 「確認」 compares to `tokens` (exact order; case-sensitive except first token); feedback + correct sentence + audio; feeds SRS as Good/Again. |
| `/type/` | 書いて練習 | JA prompt; text input (font-size ≥16px, `autocapitalize="sentences"`, `autocorrect="off"`, `spellcheck="false"`, `lang="de"`); umlaut buttons ä ö ü ß Ä Ö Ü inserting at cursor; result: correct / almost (word diff shown, user self-grades) / wrong. |
| `/cloze/` | 穴埋め | Pick a token that is an article/determiner (der die das den dem des ein eine einen einem einer eines, kein-, mein- … forms) or a preposition; 4 choices from the same family; one gap per sentence; skip sentences without a candidate. |
| `/browse/` | 文一覧 | Search (DE/JA), filter by level and tag; each row: DE, tap to reveal JA + reading + variants (別の言い方); audio button; tags link to grammar. |
| `/grammar/` | 文法ノート | List grammar.json tags grouped by CEFR; detail anchors; 「この文法の例文」 link to `/browse/?tag=<id>`; banner 「確認中の下書きです」 while `status == "draft"`. |
| `/settings/` | 設定 | new cards/day, speech rate (0.7–1.1), show reading line, export (copy code + download `.json`), import (paste or file), reset (double confirm). |

Shared: `src/layouts/Base.astro` (props `title`, `active`), bottom tab bar on phones (ホーム/復習/練習/一覧/設定 — 練習 opens a small menu or page linking build/type/cloze), top bar on wide screens. Footer: privacy note JA + DE (anonymous usage statistics via Umami when enabled; progress stays on the device), credits 「例文：Nikku 作成、日本語は友人がレビュー」.

## 4. Logic modules (`src/lib/`)

- `srs.ts` — **port of the Android app's scheduler** (Learning App repo, `core/domain/.../engine/srs/`: `SrsScheduler.kt`, `SrsConfig.kt`, `LearningDay.kt`, `SrsSnapshot.kt`). Same algorithm, same constants, deterministic (time passed in, no `Date.now()` inside). Port the relevant cases of `SrsSchedulerTest.kt` to `tests/srs.test.ts` with the same expected values.
- `answer.ts` — `normalize(s)` (NFC, trim, collapse spaces, strip trailing/leading punctuation „"“”‚'.,!?;:, lowercase, ae/oe/ue → ä/ö/ü only when the expected text has the umlaut at that position — implement as comparing both sides after mapping ä→ae, ö→oe, ü→ue, ß→ss), `grade(expected, given) -> {verdict: "correct"|"almost"|"wrong", diff: Array<{word, status}>}`; "almost" = normalized Levenshtein distance ≤ 2 chars or exactly one word wrong/missing, plus report missing noun capitalisation as a hint (`hints: ["capitalization"]`).
- `cloze.ts` — candidate selection + distractors (deterministic given a seed).
- `storage.ts` — namespaced `dfj:v1:` keys; every access in try/catch; in-memory fallback; `exportState() -> string` (JSON with `schema: 1`, `exportedAt`), `importState(string)` with validation; `navigator.storage.persist()` attempted once (guarded).
- `speech.ts` — `speak(text, rate)` using `speechSynthesis` with a `de-DE` voice (prefer names containing "Anna" or the first `de` voice); no-op with a visible hint when unavailable. Only called from a user tap.
- `shuffle.ts` — seeded PRNG (mulberry32) for chips/distractors; tests.

## 5. PWA

- `public/manifest.webmanifest` (name 「ドイツ語練習」, short_name 「ドイツ語」, `start_url` and `scope` = base path, `display: standalone`, theme/background colours), icons 180/192/512 PNG + maskable, generated by `scripts/make-icons.mjs` (sharp) from `public/icon.svg`; `apple-touch-icon` link.
- `public/sw.js`: cache name includes the build version; precache the pages + `_astro` assets listed in a generated `sw-manifest.json` (written after build, or computed at runtime from a list the build emits); network-first for HTML, cache-first for hashed assets. **Kill switch:** if `GET <base>sw-kill.json` returns `{ "kill": true }`, the worker unregisters itself and clears its caches. Ship `sw-kill.json` with `{ "kill": false }`.
- Registration only in production builds, scope = base path.

## 6. iPhone checklist

`viewport-fit=cover`, safe-area insets, `100dvh`, tap targets ≥44 px, no hover-only interactions, inputs ≥16 px, `-webkit-tap-highlight-color: transparent`, audio only after a tap, works offline after first visit, dark mode via `prefers-color-scheme`, Japanese font stack `"Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP", system-ui, sans-serif`.

## 7. Deploy

`.github/workflows/deploy.yml`: on push to `main` + manual; Node 22+; `npm ci`, `npm test`, `npm run build` with env `SITE_URL`, `BASE_PATH`, `PUBLIC_UMAMI_WEBSITE_ID` from repo **variables** (`vars.*`, defaults `https://nikkuisryu.github.io`, `/deutsch-for-japanese`, empty); upload with `actions/upload-pages-artifact`, deploy with `actions/deploy-pages`. `astro.config.mjs` reads `SITE_URL`/`BASE_PATH` from `process.env`. Custom domain switch: set Pages custom domain `deutsch.nikku.tech` in repo settings, set variables `SITE_URL=https://deutsch.nikku.tech`, `BASE_PATH=/`.

## 8. Content follow-ups (not blocking v1)

- `content/review/de_polish_candidates.csv`: German sentences that read stilted (owner's German pass).
- `content/drafts/`: B1/B2 gap sentences (not shipped until reviewed by owner (DE) and a Japanese friend (JA)).
- Variants and own German glosses (`ja_words_de`) are not reviewed yet; glosses are not used in v1.
